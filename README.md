# 图书馆座位预约系统（模仿 CCNU 图书馆座位预约 · 网页版）

华中师范大学图书馆风格的座位预约系统 Web 实现，包含**用户端**与**管理员端**。界面参考 CCNU 图书馆座位预约 App 并重新设计排版与座位布局（主校区 / 南湖分馆双馆区）。

> 纯前端实现（HTML + CSS + 原生 JavaScript），数据保存在浏览器 localStorage，双击即可打开使用，无需服务器。

## 快速开始

直接用浏览器打开：

| 入口 | 文件 | 说明 |
| --- | --- | --- |
| 用户端 | `index.html` | 注册 / 登录 → 预约选座 |
| 管理员端 | `admin.html` | 账号 `admin` 密码 `admin123` |

> 演示账号（用户端）：学号 `1`～`5`，密码均为 `123456`（也可自行注册）

## 用户端功能

- **注册 / 登录**：学号 + 密码
- **预约选座**：
  - 选择日期（仅今天与明天；明日座位每日 **18:00** 后开放，今日 **22:00** 后截止）
  - 切换馆区（主校区图书馆 / 南湖分馆）→ 选择楼层 → 查看区域列表与可用座位数
  - 座位分布图（多种布局：开敞矩形 / 中庭回环 / 卡座 / 圆桌 / 自习间）
  - 座位状态：绿色=可预约、红色=已预约、橙色=暂离中、灰色=停用
  - 点击座位后弹窗选择时间段，时间轴中标红已被预约的时段，只能选择绿色连续段
- **预约成功弹窗**：提示签到窗口（预约时间点前后 30 分钟）+ **当日天气**（Open-Meteo 实时天气，离线自动降级为演示数据；天冷提醒加衣、天热提醒防晒、降雨提醒带伞）
- **预约记录**：
  - 状态流转：待签到 → 履约中 → 暂离中 → 已结束 / 违约
  - 待签到：签到窗口内可点击「现在签到」；超时自动记为违约并释放座位
  - 履约中：可「暂离」（保留 90 分钟）或「结束预约」
  - 暂离中：可「回馆」恢复座位；超过 90 分钟未返回自动记为违约
  - 预约详情：时间线展示 签到 / 暂离 / 回馆 / 结束预约 各时间点
- **通知公告**：展示管理员发布的公告
- **我的**：总预约数、违约次数、履约中数量
- **演示时间**：右上角 ⏱️ 可设置模拟当前时间，便于完整体验签到、暂离、违约、结束全流程（仅本地生效，关闭后恢复真实时间）

## 管理员端功能

- **登录**：`admin` / `admin123`
- **数据看板**：今日预约数、履约中、违约数、累计预约；各楼层座位利用率；近 7 日预约趋势
- **预约管理**：全部预约列表（状态筛选），可取消预约
- **座位管理**：按馆区 / 楼层 / 区域查看座位分布，可停用 / 启用座位，查看某座位当日占用时段
- **用户管理**：用户列表、违约次数、重置违约
- **公告管理**：发布 / 删除用户端可见公告

## 预约规则（参考 CCNU 图书馆座位预约系统）

- 开放时间：周一至周日 7:30—22:00（周五 14:00 后闭馆）
- 签到：预约时间点前后 30 分钟内签到，超时记违约 1 次并释放座位
- 暂离：保留座位 90 分钟，超时未返回记违约并释放座位
- 违约上限：每月 4 次，满 4 次暂停预约系统 7 天
